## Como penso engenharia

**Prefiro evidência a alegações.**  
Código executável, testes, arquitetura e reprodução do ambiente valem mais do que listas extensas de tecnologias.

**Integridade também pertence ao banco.**  
Validação na aplicação é importante, mas transações, constraints e controle de concorrência continuam necessários.

**Trade-offs precisam ser documentados.**  
Um protótipo não precisa fingir que é uma plataforma de produção, e código histórico não deve ser reescrito para parecer mais novo do que realmente é.

**A origem do código precisa ser clara.**  
Trabalho autoral, sistemas legados, material de curso e código de terceiros devem ser identificáveis como coisas diferentes.
