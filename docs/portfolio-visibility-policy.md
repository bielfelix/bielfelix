# Portfolio visibility policy

The public profile should prioritize original engineering work.

Repositories based substantially on externally authored source material are preserved for provenance and technical reference, but they do not need to compete with original flagship work in the public portfolio.

## Recommended private/reference repositories

- `NeuroCart`
- `smart-model-router-gateway`
- `project-node-grafana-mcp`
- `project-node-embeddings-neo4j`
- `project-node-langchain`
- `project-node-medical-appointment`
- `E-commerce-Recommendation-System-MongoDB-API-Architecture`
- `ecommerce-recomendations-with-ml`
- `icons-svg`
- `How-to-win-any-game-beta`

The first group incorporates external source material with explicit provenance/licensing boundaries. The final two are third-party reference copies.

This is a portfolio-curation decision, not a claim that the repositories have no technical value.
